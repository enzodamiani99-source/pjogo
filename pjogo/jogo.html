⚔️ Arena de Duelo

Prepare-se para enfrentar o poderoso Mago Sombrio em um duelo mágico de cartas.

🎯 Objetivo do Jogo

O objetivo é derrotar o Mago Sombrio reduzindo sua vida (HP) para zero.

Para isso, você deverá usar cartas estratégicas com habilidades especiais.

📖 Como Jogar

  1. Você começa com cartas aleatórias.
  2. Só pode jogar cartas da mesma cor ou do mesmo número.
  3. Cada elemento possui um efeito especial durante o combate.
  4. O turno alterna entre jogador e bot.
  5. O jogador que zerar a vida do inimigo vence.

🖱️ Comandos do Jogo

  • Clique na carta → joga a carta escolhida.
  • Comprar → compra uma nova carta.
  • Nova batalha → reinicia o duelo.

🔮 Tipos de Carta

  • 🔥 Fogo → dano dobrado.
  • 💚 Cura → recupera HP.
  • ❄️ Gelo → congela o turno do inimigo.
  • ⚡ Raio → destrói carta inimiga.
